# 운영체제 — 동시성 기초

프로세스는 실행 중인 프로그램을 뜻한다. 스레드는 프로세스 안에서 실행되는
더 작은 실행 단위이며, 하나의 프로세스는 여러 개의 스레드를 가질 수 있다.

프로세스끼리는 메모리를 공유하지 않는다. 반면 같은 프로세스에 속한
스레드끼리는 메모리를 공유한다. 이 점이 둘을 구분하는 가장 큰 차이다.

여러 스레드가 같은 자원에 동시에 접근하면 경쟁 상태가 발생한다.
경쟁 상태를 막으려면 임계 구역에 한 번에 하나의 스레드만 들어가도록
통제해야 한다.

뮤텍스는 임계 구역에 잠금을 걸어 경쟁 상태를 해결한다. 세마포어도 비슷한
목적으로 쓰이지만, 뮤텍스가 한 번에 하나의 스레드만 허용하는 반면
세마포어는 미리 정한 개수만큼 동시 접근을 허용한다. 두 개념은 역할이
비슷해 학습자들이 자주 헷갈린다.

두 스레드가 서로 상대가 쥔 잠금을 기다리며 멈추면 데드락이 발생한다.
데드락은 시스템 행을 유발한다.

경쟁 상태를 이해하려면 임계 구역이 무엇인지 먼저 알아야 한다.
